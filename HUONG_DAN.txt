========================================
  Ghost Story Piano
========================================

Folder: ~/Documents/GhostStory-Piano

  input/          ← file .mid sẵn sàng convert
  parts/          ← phần lẻ name.mid, name1.mid… (chưa ghép)
  input/letter_notes/
  output/         ← kết quả mỗi bài 1 folder
  convert.sh      ← MIDI → Ghost Story
  merge_midi.sh   ← ghép parts/ → input/*_gop.mid
  convert_letter.sh ← Letter notes → Ghost Story

Cài 1 lần:
  cd ~/Documents/GhostStory-Piano
  pip3 install -r requirements.txt

========================================
CÁCH 1: MIDI
========================================

1. Bỏ file .mid vào input/
2. Chạy:
     ./convert.sh ten_bai.mid
     ./convert.sh ten_bai.mid --bpm 90

3. Kết quả:
     track_A_single.ghost.txt     ← Track A (giai điệu mono)
     track_B_harmony.ghost.txt    ← Track B (hòa âm)
     track_C_bass.ghost.txt       ← Track C (bass)
     gop_ABC.mml.txt              ← MML@T…A…,T…B…,T…C…;

4. Copy A/B/C → Track A/B/C trong game · tốc độ ≈ BPM
   (hoặc copy gop_ABC.mml.txt nếu tool hỗ trợ MML@)

Ghép nhiều phần cùng bài:
  1. Bỏ phần lẻ vào parts/ (không bỏ lẫn input/):
       parts/ten_bai.mid
       parts/ten_bai1.mid
       parts/ten_bai2.mid
     (hoặc parts/ten_bai/ten_bai.mid, ten_bai1.mid, ...)
  2. Chạy:
       ./merge_midi.sh ten_bai
       ./merge_midi.sh ten_bai --convert
     → tự tạo input/ten_bai_gop.mid

========================================
CÁCH 2: Letter notes (paste 4|...|)
========================================

Format (pianoletternotes):
  4|G-G--G--F-e-C-------------|
  3|-------------C------------|
  3|-------------e------------|
  2|-------------a------------|
  1
  4|-GG---G--F-eD-------------|
  ...

Quy tắc: chữ thường = nốt trắng; A C D F G hoa = # ;
số đầu dòng = octave; - = nghỉ; số 1,2,3… = ô nhịp (bỏ qua).

1. Paste vào:
     input/letter_notes/ten_bai.txt
   (xem mẫu: input/letter_notes/_MAU.txt)

2. Chạy:
     ./convert_letter.sh ten_bai.txt --bpm 100
     ./convert_letter.sh ten_bai.txt --bpm 100 --title "Ten Bai"

3. Kết quả:
     output/ten_bai/track_A_ghoststory.txt

4. Copy hết → dán Track A · tốc độ ≈ BPM đã chọn

Tuỳ chọn:
  --bpm 100       tốc độ
  --title "Tên"   tên folder output
  --min-oct 5     chỉ lấy octave cao (nếu >3000 ký tự)
  --key Am

========================================
LƯU Ý
========================================
- Giới hạn Track A: 3000 ký tự
- MIDI convert: lưới 1/64 (có l32/r64, l mặc định) — chi tiết kiểu MabiIcco
- Letter notes: cùng cột nhiều nốt → giữ nốt cao (giai điệu)
- Octave thấp (< 4) mặc định bỏ (bass LH)
